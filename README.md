# 🛒 E-Commerce Cart System (Python)

A command-line based **E-Commerce Cart System** built using Python.
This project allows users to browse items, add/remove products, manage budget, and place orders with additional features like flash sales.

---

## 🚀 Features

* 🛍️ Display available products
* ➕ Add items to cart
* ➖ Remove items from cart
* 💰 Calculate total price
* ⚡ Flash sale pricing (limited time discounts)
* 🎯 Budget management (limit spending)
* 🧾 Order placement with random Order ID
* 📊 Cart display using pandas table format

---

## 🧠 Concepts Used

* Python Basics
* Data Structures (**Linked List for cart management**)
* Dictionaries & Lists
* OOP Concepts (Classes & Objects)
* Regular Expressions (User ID validation)
* Multithreading (`Timer` for flash sale)
* Pandas (for cart display)

## ▶️ How to Run

1. Install required library:

```bash
pip install pandas
```

2. Run the program:

```bash
python E-Commerce.py
```

---

## 🧑‍💻 Usage

* Enter a valid **User ID** (must contain letters and numbers)
* Choose options from menu:

  * View items
  * Add/Remove products
  * Set budget
  * View cart
  * Place order

---

## ⚡ Flash Sale Feature

Some items have **limited-time discounted prices**.
After the timer ends, prices return to normal automatically.
